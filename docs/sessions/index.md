# セッションの進め方と開催予定

各回は独立したテーマとし、前回までの知識は前提としない形式で進めます。いつからでも
ご参加いただけます。各回は **A日程・B日程の2日程で、同じ内容** を開催します。
進め方・手元に残るもの・今後の開催予定をまとめています。

<a id="flow"></a>

## 1回の流れ

テーマに応じて構成は調整しますが、おおむね次の流れで進めます。

{{ session_flow() }}

## セッション後にお手元に残るもの

- 当日のスライド
- 使ったファイルと指示文（Google Colab で動かせるものを含む）
- A・B日程それぞれの録画と音声、文字起こし、ダイジェスト記事
- 事前に作り込んだ発展版のアプリのデモと解説
- 各自でバリエーションを広げるための自習ガイド

有償メンバーは、入会した日から、これまでのすべての回の記録を見られます（メンバースペース）。
各回を場面ごとに見返せるビューア、「必見だけ20分」の見方、これまでの記録を言葉で探して聞ける機能、
業界×業務で並べた課題の棚（AIで解決に挑戦できるテーマ集。{{ config.extra.lp.issues_count }}）もあります。

## 参加者コミュニティ（Circle）

有償メンバーには、参加者向けコミュニティ（Circle）へのご招待をお送りします。各回のご案内、過去回の
アーカイブ、参加者同士のディスカッションに加えて、毎朝、AIがニュースを集め、これまでの回と結びつけて
読み解いた投稿が届きます。AI時代の戦略の引き出しを、継続して積み重ねる場です。
