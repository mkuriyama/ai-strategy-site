# 登録方法

入口は2つあります。情報を受け取りながら検討したい方は **無料のメール登録** から、すでに参加を
決めている方は **[今すぐ申し込む](#今すぐ申し込む)** から、そのままお申し込みいただけます。

## 案内メールを受け取る（無料）

次回以降（月1回予定）の参加案内、追加開催（サブ回）のご案内、今後の開催に関する継続的な情報を、
順次メールでお送りします。以下のいずれのご意向でも、まずはご登録ください。

- 次回セッションへの参加を希望
- 日時が合わないが、録画視聴での参加を希望／別日程（サブ回）があれば参加希望
- 継続参加（月次）を検討
- 現時点では未定だが、本プロジェクトの継続的な案内を希望

!!! info "メール配信について"
    ご案内配信メールは **support@antecanis.com** からお送りします。プロモーションメール等に
    紛れて見落とされないよう、連絡先登録やメール振り分けでの対応をお勧めします。配信は
    いつでもご自身でキャンセルできます。ご登録後、開催案内を順次メールでお送りします
    （オンライン会場のZoom情報・当日資料は、お申し込み後にご案内します）。

## ご参加の流れ

1. 案内メールに登録（無料）。次回以降の開催案内を順次メールで受け取る。参加を決めている方は
   この手順を省いて2から進めます。
2. Stripeで参加のお申し込み（決済登録）。**申込当月回は無料**、翌月回から課金開始（いつでもご自身で解約可）。
3. お申し込み後に、オンライン会場（Zoom）情報・当日資料と、参加者コミュニティ（Circle）への
   ご招待を受け取る（会場リンク・資料は主に Circle 内でご案内します）。

参加費・課金のしくみは **[参加費と決済](index.md)** に図でまとめています。どなたに向けた
場かは **[背景と狙い](../about/index.md#想定参加者)** をご覧ください。

## 今すぐ申し込む

内容をご存知の方・参加を決めた方は、メール登録を経由せず直接お申し込みいただけます。お申し込み
の前に、下の3点をご確認ください。

- **申込当月の回は無料です。** お申し込みいただいた当月のセッションに費用はかかりません。
- **課金は毎月15日。** 初回課金は申込翌月の15日、以降は毎月15日が課金日です。
- **いつでもご自身で解約できます。** 課金日の前日までに解約すれば、その月は¥0です。
